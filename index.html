Под капотом

Как работает «Горизонт»

Каждые два часа GitHub Actions запускает Python-сборщик: он опрашивает 17 региональных версий Bing, дедуплицирует кадры и дописывает новые ссылки в data.json. Сами изображения не хранятся в репозитории — архив бережёт прямые CDN-ссылки на оригиналы UHD и обновляет кадр дня прямо в HTML этой страницы.

Репозиторий на GitHub

Код — MIT. Изображения © Microsoft Bing и их правообладателей; архив хранит только ссылки.

01Сборщик

fetch_bing.py · 17 рынков · ретраи и дедупликация · запуск каждые 2 часа по cron · инъекция свежего LCP-кадра в index.html.

02Хранилище

data.json в репозитории · прямые ссылки на UHD-оригиналы · названия и подписи из API · коммиты только при изменениях.

03Просмотрщик

Чистый HTML/CSS/JS без фреймворков · адаптивные thumbnails вместо тяжёлых превью · dialog-лайтбокс · избранное в localStorage · эта страница.
