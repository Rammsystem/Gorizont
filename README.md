Автоматизированный веб-архив ежедневных фоновых изображений Bing в разрешении Ultra HD (4K), собранных из 17 регионов мира.

> 🚀 **Рабочий сайт доступен по адресу:** [gorizont.isvii.ru](https://gorizont.isvii.ru/)

---

## Зачем я это сделал?

Обои на главной странице Bing сменяются каждые сутки и исчезают. Проект «Горизонт» создан для автоматического сохранения всей коллекции в одном месте без потери оригинального качества и дублирования файлов.

## Как это работает

- **Сборщик (Collector):** Скрипт на Python (`fetch_bing.py`) опрашивает API Bing по 17 локальным рынкам. Запуск обновления происходит раз в два часа.
- **Хранилище (Storage):** База данных хранится в `data.json`. Сами изображения не занимают место в репозитории — сохраняются прямые CDN-ссылки на оригиналы UHD. Одинаковые изображения из разных стран дедуплицируются в одну запись.
- **Просмотрщик (Viewer):** Легковесный интерфейс на чистом HTML5/CSS3/JavaScript без сторонних фреймворков. Поддерживает нативный `<dialog>`-лайтбокс, предпросмотр, полноэкранный режим и скачивание UHD. Если браузер блокирует прямую загрузку из-за CORS на стороне Bing, кнопка автоматически переключается в режим «Открыть UHD» — файл можно сохранить через меню браузера.

## Архитектурные особенности

- **Дедупликация:** При выходе одних и тех же обоев в разных странах скрипт объединяет их в одну запись, добавляя коды регионов в список `markets`.
- **Нормализация ID:** Служебные суффиксы рынков (например, `_EN-US`, `_ROW`) очищаются регулярным выражением для формирования стабильных идентификаторов.
- **Нулевые зависимости:** Проект не требует сторонних библиотек (`pip`) — используется только стандартная библиотека Python и нативный браузерный API.
- **Бережная работа с памятью:** Временные Blob URL и контроллеры загрузки (`AbortController`) корректно очищаются при закрытии и навигации.

## Поддерживаемые рынки

`en-US`, `en-AU`, `en-CA`, `zh-CN`, `de-DE`, `es-ES`, `fr-FR`, `it-IT`, `ja-JP`, `en-NZ`, `en-GB`, `nl-NL`, `pl-PL`, `pt-BR`, `pt-PT`, `ko-KR`, `ru-RU`.
